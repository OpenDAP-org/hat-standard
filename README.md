# HAT Case Standard

The HAT Case Standard: device side and accessory side. A HAT swaps the basic back cover for a HAT case; this standard defines that rear interface (mechanics, pinout, electrical, identification EEPROM, overlays), plus reference designs and a compliance kit for accessory developers.

## Layout

- `spec/`
- `reference-designs/`
- `compliance/`
- `export/`
- `docs/`
